## Pipeline (all under ~/capture/linkding on the VM)
1. `python3 seed.py init`; `docker compose -p rea-linkding -f compose.yml up -d`.
2. `python3 seed.py` (stdlib, idempotent by URL and name; re-run three times without changes): signs in through the Django
   login form (`/login/`, csrfmiddlewaretoken), then uses DRF session authentication on `/api/` with `X-CSRFToken`.
   linkding renames Django's cookies to `ld_sessionid` and `ld_csrftoken`, which the first seed version missed.
   Content: 6 bookmarks on invented `*.example.test` URLs with titles, descriptions and notes ("Granite Ledger quarterly
   stone count", "Blue Heron Kitchen tide-table menu" (unread), "Saltmarsh Depot gate log", "Copperfield Annex cart
   register" (archived), "Lighthouse Rota winter shift plan", "Tide tables for January" (archived)), created with
   `?disable_scraping&disable_html_snapshot`; 8 tags (7 through bookmarks, `night-shift` through `POST /api/tags/`);
   bundles "Quarry and depot audits" (any_tags granite-ledger saltmarsh-depot, excluding menus) and "Blue Heron reading
   list" (all_tags blue-heron-kitchen, search kelp); a text asset `granite-ledger-gl-2291-tally.txt` uploaded to the Granite
   Ledger bookmark (multipart, `POST /api/bookmarks/{id}/assets/upload/`). Removes leftover scratch bookmarks.
   Writes `seed-ids.json` (ids only).
3. `NODE_PATH=~/capture/node_modules node linkding/capture.mjs`: UI login through the form, then 48 scripted in-page
   reads (profile; bookmarks list, 6 bookmarks by id, `limit/offset` pages incl. a one-by-one walk, `q` searches with
   linkding syntax `#audit`, `kelp`, `!unread`, `#lighthouse-rota`, `Okafor`, `#audit #granite-ledger`, two `bundle=` filters;
   archived list and `q=tide`, `q=#copperfield-annex`; shared list (empty, sharing is off); `check/?url=` for three saved URLs
   and one unsaved; asset list and asset by id, an empty asset list; tags list, paged list and 8 tags by id; bundles list
   and 2 by id), then the UI pages `/bookmarks`, `/bookmarks?q=#granite-ledger`, `/bookmarks/archived`, `/tags`, `/bundles`,
   `/settings`, then the write path: scratch bookmark POST (201), PATCH, archive (204), GET, unarchive (204), PUT, DELETE (204),
   GET (404); scratch tag POST, GET, DELETE; scratch bundle POST, PATCH, DELETE; final bookmark and bundle lists.
   linkding's own UI is server-rendered and calls no `/api/` route, so every kept record comes from the scripted sequence.
4. `python3 -I ~/capture/scope_har.py linkding.full.har linkding.scoped.har --origin http://127.0.0.1:3203 --keep-regex '^/api/'`
   -> kept 64 (GET 53, POST 5, PATCH 2, PUT 1, DELETE 3); dropped path 50 (HTML pages, static), auth 2 (login GET/POST),
   other 0. Statuses 200 x55, 201 x3, 204 x5, 404 x1. 97,323 bytes, sha256
   `255d191acf58773d0d7376a2d048dc6296f9c7baa6e7ae675053506734ff2b40`. Credential grep: admin password 0 hits,
   `hf_`/`ghp_`/`Bearer ` 0, cookie names 0, no secret-looking keys in any response body.
5. `python3 ~/showcase/envbuild.py all linkding`.

## Build results
- Bundle: 11 retrieval tasks from 11 candidates (every readable GET tool; `get_bookmarks_shared` is an empty list and
  yields no candidate). `exclude_tools` only removes download/health/version, none of which were captured.
- Smoke passed (26.8 s).
- Eval: `openai/gpt-oss-120b:groq` **10/11**, `zai-org/GLM-5.3-Flash:zai-org` **11/11**; mean input tokens 6,236 and 7,665.
  The miss (`qa-09`) is a provider rejection of the model's tool call: gpt-oss sent `null` for every optional query
  parameter of `get_bookmarks` and the provider's schema validation answered 400; written into `episode_notes`.
- Dry publish: 12 tasks, 23 runs (22 eval episodes + smoke) in `~/showcase/datasets/linkding`, 6.5 MB; scans clean.

## Things a reader should know
- Every bookmark response carries `web_archive_snapshot_url`, a link linkding computes on the Internet Archive's
  public host for the bookmark's URL and date even though the web archive integration is disabled. It is app-generated
  (the bookmark URLs inside it are the invented `example.test` ones) and no task asks for it (URL-like fields are skipped).
- `check/?url=` makes linkding try to load the page metadata; the invented hosts do not resolve, so `metadata` is all null.

## Teardown
